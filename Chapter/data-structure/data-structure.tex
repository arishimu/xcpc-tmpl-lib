\subsection{带权并查集}

$x, y \in X$ 不仅有关系，还带权 $f(x, y)$，满足{\bf 自反性} $f(x, x) = 1_X$，并且存在运算 $\circ$，使得权值 $f$ 满足{\bf 传递性}
$$
f(x, z) = f(x, y) \circ f(y, z)
$$
只要存在运算 $\neg$，使得权值 $f$ 满足{\bf 对称性}
$$
f(y, x) = \neg f(x, y)
$$
那么 $f$ 可以使用带权并查集来维护．

设 $x, y$ 的根分别为 $r_x, r_y$，
已知 $f(x, y), f(x, r_x), f(y, r_y)$，
欲使 $r_{r_x} = r_y$，有
$$
f(r_x, r_y) = \neg f(x, r_x) \circ f(x, y) \circ f(y, r_y)
$$
由于自反性，如果合并时已经有 $r_x = r_y$，那么右式必等于 $1_X$，利用这一点来判断关系 $f$ 是否良定义．
在这之后的适当时机（查询时），修正 $f(x, r_x) \mapsto f(x, r_x) \circ f(r_x, r_y)$．

最经典的 $f$ 是数轴上两点的有向距离（如区间和），也可以是环上的两点距离（如“食物链”的模 $n$ 加法群）．
下面以异或为例：自反性 $x \oplus x = 0$，传递性 $x \oplus z = (x \oplus y) \oplus (y \oplus z)$，
对称性 $y \oplus x = x \oplus y$，使用带权并查集维护：

\subsection{可持久化并查集}

可持久化并查集是 leafy 的．

对{\tt fa}和{\tt sz}数组实现了可持久化，单次访问 $O(\log n)$．

对两棵树启发式合并，保证了树高是 $O(\log n)$ 级别，
因此一次查询是 $O(\log^2 n)$ 的．

\begin{enumerate}[noitemsep]
    \item {\tt PDSU()}：初始化从节点 $0$ 到节点 $n - 1$ 的并查集作为第 $0$ 个版本，$m$ 是对最大版本数的估计；
    \item {\tt latest()/latest\_()}：返回最近版本号/根节点；
    \item {\tt save()/save\_()}：传入版本号/根节点，拷贝该版本作为新版本；
    \item {\tt find()/find\_()}：传入版本号/根节点、索引{\tt i}，返回同类的代表（叶）节点以及对应的索引；
    \item {\tt same()/same\_()}：传入版本号/根节点、两个索引，判定是否同类；
    \item {\tt merge()/merge\_()}：传入版本号/根节点、两个索引，合并后{\bf 自动产生新版本}；
    \item {\tt merged()/merged\_()}：传入版本号/根节点、两个索引，合并后{\bf 返回新根，不产生新版本}；
    \item {\tt leaf()/leaf\_()}：传入版本号/根节点、索引{\tt i}，返回对应的叶节点；
    \item {\tt modify()/modify\_()}：传入版本号/根节点、待修改节点的索引{\tt i}、修改内容（{\tt fa}和{\tt sz}），返回新根．
\end{enumerate}

\subsection{树状数组}

数组元素 $a_i \in A$，对 $a$ 交替进行：
{\bf 单点修改} $a_i \mapsto a_i * x$；
{\bf 前缀查询} $S(k) = \prod_{0 \le i < k} a_i$．

如果 $(A, *)$ 构成{\bf 半群} (即 $*$ 仅满足结合律)，那么可以使用树状数组 $p$ 来维护 $a$：
$$
p_k = \prod_{k - \text{lowbit}(k) \le i < k} a_i, \quad
1 \le k \le n
$$
每个 $p_k$ 管辖了在 $a_k$ 前面 $\text{lowbit}(k)$ 个元素．
实践中，为了方便建树与查询，我们额外要求 $(A, *)$ 具备{\bf 幺元}，即幺半群，并把幺元记为 {\tt id}．

前缀查询时，$S(k)$ 始终能被拆成 $O(\log k)$ 个 $p_i$ 之积，以达成 $O(\log n)$ 的查询复杂度，常数因子非常优秀．
具体来说，$S(k)$ 能按照 $k$ 的二进制表示，被拆成 $\text{popcount}(k)$ 个 $p_i$ 之积．例如 $k = 22$ 的情形：
$$
\begin{aligned}
    (10110)_2 &= (10000)_2 + (00100)_2 + (00010)_2 \\
    [0, 22) &= [0, 16) \cup [16, 20) \cup [20, 22) \\
    S(22) &= p_{16} * p_{20} * p_{22}
\end{aligned}
$$

单点修改时，只需修改 $O(\log n)$ 个管辖范围包含 $a_i$ 的区间．
修改区间从 $p_{i+1}$ 开始，能够证明 $p_k$ 的下一个管辖范围包含 $a_i$ 的区间是 $p_{k + \text{lowbit}(k)}$．

实现上（下标均为 0-based）：

\begin{enumerate}[noitemsep]
    \item {\tt Fenwick(n, id)}：建出全幺元的空树；
    \item {\tt Fenwick(v, id)}：以数组 {\tt v} 建树，时间复杂度 $O(n)$；
    \item {\tt add(k, v)}：单点修改，$a_k \mapsto a_k * v$；
    \item {\tt ask(k)}：前缀查询，返回 $S(k) = \prod_{0 \le i < k} a_i$．
\end{enumerate}

$p$ 数组以 {\tt info} 为名公开，{\tt info[i]} 对应 $p_i$，
因此也可以不用 {\tt ask}，直接在树状数组上倍增：
从高位到低位尝试把下标 {\tt cur} 调大，只要累积的前缀积仍不超过阈值就保留这一位．
这样能在 $O(\log n)$ 内求出前缀积不超过阈值的最大下标，
示例用它在离散化（{\tt Disc}）后的桶计数上查询全局第 $k$ 小．

\subsection{线段树}

今有半群 $(D, +)$．
和树状数组一样，线段树能维护由{\bf 半群}元素构成的数组，比如区间和/积、区间最值、区间 gcd．
相比树状数组使用二进制结构维护区间片段以合成前缀区间，线段树直接二分区间直至区间长度为 $1$，因此可以实现任意的{\bf 区间查询}．
如果只有{\bf 单点修改}的需求，可以不用实现懒标记．

在实践中，为了方便合并子区间信息与初始化叶节点，我们额外要求 $(D, +)$ 还具备{\bf 幺元}，即幺半群．
实现上不要求 {\tt Info} 自带成员函数，而是把 $+$ 与叶节点初始化写成编译期传入的可调用对象：

\begin{enumerate}[noitemsep]
    \item {\tt Merge}：$D \times D \rightarrow D$，充当运算 $+$；
    \item {\tt Init}：$l \mapsto D$，给出叶节点 $l$ 的初始信息，默认为幺元．
\end{enumerate}

下标与区间端点使用 {\tt i64}．使用时：

\begin{enumerate}[noitemsep]
    \item {\tt build(L, R, init)}：在区间 $[L, R)$ 上建树，{\tt init(l)} 给出叶节点 $l$ 的初始信息；
    \item {\tt modify(i, f)}：单点修改，{\tt info[i] = f(info[i])}，{\tt f} 是 $D \rightarrow D$ 的函数对象；
    \item {\tt query(i)}：单点查询；
    \item {\tt query(a, b)}：区间查询，汇总 $[a, b)$ 的信息．
\end{enumerate}

{\tt modify} 传入的是函数而非新值：单点赋值写成常函数即可，
而“在原值上累加”一类的修改可以直接表达，省去一次查询．

\subsection{线段树（动态开点）}

当区间分布跨度极广，但操作涉及的区间总长在可接受范围内时，可以用动态开点的方式代替直接在极广区间上建树．
此时父子节点的编号关系已不存在，需要额外维护每个节点的{\tt lson}和{\tt rson}．
每次从根出发向下递归，先 {\tt dive} 探路：缺左儿子就新开 {\tt node(l, m)}，缺右儿子就新开 {\tt node(m, r)}．

动态开点的线段树{\bf 与普通线段树使用方法完全一致}，能访问的下标得到极大扩展．
使用前需给定全局最广区间{\tt [L, R)}，但请注意：{\bf 越广的区间意味着越大的常数}．

与普通线段树相比只有两点不同：

\begin{enumerate}[noitemsep]
    \item {\tt Init} 作用于任意节点，签名为 {\tt init(l, r)}，返回区间 $[l, r)$ 的初始信息；
    \item {\tt build} 只创建根节点，其余节点在首次被访问时创建并初始化，
        内部节点（如区间和）一次就能初始化到位，不必是幺元．
\end{enumerate}

示例用前缀和数组 {\tt p} 初始化内部节点：{\tt init(l, r) = p[r] - p[l]}．

\subsection{带懒标记的线段树}

形式化地，信息 $(D, +)$ 构成{\bf 半群}，标记 $(T, *)$ 构成{\bf 幺半群}，
另外定义 $\cdot: T \times D \rightarrow D$，并且 $\cdot$ 对 $+$ 满足{\bf 分配律}，
这种代数结构我们可以使用带懒标记的线段树来维护．为了方便合并子区间信息，我们额外要求 $(D, +)$ 还具备幺元，即幺半群．

实现上把 $+$、$\cdot$、$*$、初始化都写成编译期传入的可调用对象，{\tt Info} 和 {\tt Tag} 只需是普通结构体：

\begin{enumerate}[noitemsep]
    \item {\tt Merge}：{\tt Info(Info, Info)}，即 $(D, +)$；
    \item {\tt Init}：{\tt Info(i64)}，叶节点初始化，默认为幺元；
    \item {\tt ApplyToInfo}：{\tt void(Tag, Info \&)}，原地施加 $\cdot$；
    \item {\tt ApplyToTag}：{\tt void(Tag, Tag \&)}，原地复合 $*$；
    \item {\tt ReadyToApply}：{\tt bool(Tag, Info)}，判断标记能否直接作用在整个节点上，默认为恒真．
\end{enumerate}

{\tt Tag} 的幺元在 {\tt build} 时一并传入（默认为 {\tt Tag\{\}}），用于 {\tt push} 清空标记．使用时：

\begin{enumerate}[noitemsep]
    \item {\tt build(L, R, init, id)}：在区间 $[L, R)$ 上建树；
    \item {\tt modify(i, t)}：单点施加标记 {\tt t}；
    \item {\tt modify(a, b, t)}：区间施加标记 {\tt t}；
    \item {\tt query(i)} / {\tt query(a, b)}：单点/区间查询．
\end{enumerate}

{\tt ReadyToApply} 服务于{\bf 势能线段树}（Segment Tree Beats）：
若标记不能整体作用在节点上（例如区间取最值会破坏多个不同量级的最值），就返回假，
让线段树继续递归到足够小的节点；默认恒真时退化为普通懒标记线段树．

示例支持区间加、区间 {\tt chmax}、区间 {\tt chmin}、区间求和：
{\tt Tag} 由 {\tt add}、{\tt chmax}、{\tt chmin} 组成，
{\tt Info} 记录 {\tt len}、{\tt sum}，最大值 {\tt max1} 及其出现次数 {\tt cntx} 与次大值 {\tt max2}，
最小值 {\tt min1} 及其出现次数 {\tt cntn} 与次小值 {\tt min2}；
仅当 {\tt chmax} 落在最小值与次小值之间、{\tt chmin} 落在次大值与最大值之间时，
才允许直接作用，此时只需改写最值及其出现次数．

\subsection{带懒标记的线段树（动态开点）}

当区间分布跨度极广，但区间总长在可接受范围内时，可以用动态开点的方式代替直接在极广区间上建树．
每次从根出发向下递归，先 {\tt dive} 探路开点；
下放标记的 {\tt push} 多出区间参数，先把左右儿子开出来再 {\tt apply}．

接口与上一节完全一致：{\tt build(L, R, init, id)}、{\tt modify(i, t)}、{\tt modify(a, b, t)}、{\tt query(i)}、{\tt query(a, b)}，
只有 {\tt Init} 的签名变成 {\tt init(l, r)}，用于初始化任意节点（同动态开点的普通线段树）．
使用前需给定全局最广区间 {\tt [L, R)}，但请注意：{\bf 越广的区间意味着越大的常数}．
示例用仿射标记维护区间加、区间乘、区间赋值与区间求和．

\subsection{可持久化线段树}

仅支持{\bf 单点修改}．与可持久化并查集不同，这里不维护版本号，
而是让 {\tt modify} 直接返回新根，由使用者决定保存哪些根作为版本：

\begin{enumerate}[noitemsep]
    \item {\tt build(L, R, init)}：建出初始树并返回根，{\tt init(l, r)} 给出节点 $[l, r)$ 的初始信息；
    \item {\tt modify(p, i, f)}：以根 {\tt p} 为版本，单点修改 {\tt info[i] = f(info[i])}，{\bf 返回新根}，旧版本不受影响；
    \item {\tt query(p, i)} / {\tt query(p, a, b)}：在根 {\tt p} 上单点/区间查询．
\end{enumerate}

{\tt modify} 会克隆根到叶的整条路径，产生 $O(\log n)$ 个新节点；
{\tt dive} 在访问到不存在的儿子时补建节点，因此对任意历史版本做 {\tt query} 也是安全的．
示例是主席树：对离散化后的权值建可持久化权值线段树，
第 $i$ 个版本对应前 $i$ 个元素，区间 $[l, r)$ 的第 $k$ 小由两个前缀版本作差后在树上二分得到．
